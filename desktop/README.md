# beepOS, vaguely explained

hello, internet person. welcome to my extremely legitimate operating system.
this is a website wearing a computer costume. please act impressed.

## getting around

click stuff on the desktop. the start menu also contains stuff.
in My Computer, click a file to select it, then double-click or press Enter
to open it. on a phone, just tap it. we adapt. we evolve. we beep.

Up goes up. Back goes back. try leaving my stuff and seeing what else is on C:.
you can make folders and text files too. save your writing with Save or Ctrl+S.
the disk lives in this browser on this device; a reload won't eat your files,
but clearing this site's browser storage will. it doesn't sync to other devices.

windows have buttons in the corner. they do approximately what you'd expect.
you can drag the title bar, resize a corner, and retrieve a minimized window
from the taskbar. if things get crowded, show the desktop and start poking again.

in 1.1, the Window menu can make things less... upright. effects are optional.
if reality becomes inconvenient, Start > Reset window effects puts it back.
right-click inside My Computer for file things. deletion asks first.

## what lives here

some writing, some links, some questionable humour, and assorted bits of me.
there's a prompt if you feel like talking to the computer. it has opinions.
there are settings if the desktop needs a different mood.

that little note is editable. it saves in this browser, on this computer.
it is not a cloud service. the cloud has enough of our crap already.

## and the rest?

look around. try things. see what happens. this is a toy desktop, not a real
shell, so you aren't going to accidentally format your actual computer here.

this guide is being vague on purpose. the whole point of this site is to
explore it, and putting every easter egg in one file would ruin the surprise.

now close the manual and go be curious :3
